= Current Roc syntax coverage inventory

The authority is `roc-lang/roc` revision `7f11a825fb2df7fd48edb11e8c593ffdad4fcdb5`, `src/parse/AST.zig` and its parser/tokenizer. Legacy Rust grammar is excluded. This inventory lists compiler syntax variants; it does not assert that this parser implements them. Some variants represent malformed input or parser desugaring rather than a distinct valid surface production.

== Acceptance gate

Run `python3 scripts/check_roc_syntax_corpus.py --roc-source /path/to/roc --probe-command /path/to/probe --oracle-command /path/to/roc-syntax-oracle --output /path/to/corpus-report.json`. The workers must be freshly built from their pinned sources. The report records their executable hashes.

The gate imports the entire immutable snapshot inventory without a filter or limit. Oracle-accepted inputs require a Complete candidate parse and full consumption. Oracle-rejected inputs require candidate rejection; these include intentional errors and possibly obsolete examples, and are never treated as missing valid grammar. Worker failures, malformed protocols, source invariant failures and unhandled snapshot modes are explicit unknown failures. Every imported source and response is retained.

Acceptance agreement does not establish AST equivalence. The curated differential and independent-model lanes remain necessary. The report can be red while parser coverage is being expanded; unsupported source must never be relabelled as passing.

== Snapshot extraction audit

The parsing inventory includes ordinary and named files, exact header and
statement goals, every nonempty REPL input, and each Roc file embedded in docs
or dev-object snapshots. This exercises syntax only: it does not execute REPL
sessions, extract documentation, or run code-generation backends.

The pinned snapshot runner's `src/snapshot_tool/main.zig` is the extraction
authority. Its goal mapping is at line 992, multi-file extraction at line 3779,
REPL input classification at line 4462, and literal `»` splitting plus ASCII
trimming at line 5763. REPL input dispatch uses the `repl` worker mode; the
importer never guesses whether text is a declaration using token heuristics.
Each extracted input retains its original snapshot path and Git blob, byte
range within that blob, exact extracted-byte checksum, and final parser-input
checksum. `source_escapes=true` records the runner's explicit carriage-return
transformation. The original compiler snapshot output is not used as an
acceptance oracle.

Regression tests retain complete immutable upstream blobs for REPL,
dev-object, and docs extraction, check their Git object identities, and verify
all byte slices and hashes. In particular, documentation comments beginning
with `##` inside a Roc fence remain source text. Unknown modes, malformed
fences and empty inventories fail explicitly rather than becoming passing
skips. The only excluded inventory item is the snapshot directory README.
