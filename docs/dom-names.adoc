[#dom-names]
= Validate computed DOM names
:idprefix: _
:idseparator: _

Use `Markup.Name.from_qualified({ namespace, spelling, context })` when application
code computes a namespace-aware element or attribute name. It returns the shared
`Markup.Name` identity `{ namespace, prefix, local }` used by markup trees and
`Xml.Namespaced.Name`, without requiring a known vocabulary entry.

The `Element` context models `createElementNS`; `Attribute` models
`createAttributeNS` and `setAttributeNS`. An empty namespace URI becomes
`NoNamespace`. The constructor splits at the first colon, validates prefix and
local spelling, then checks reserved XML and XMLNS namespace rules. Failures use
`InvalidDomName(diagnostic)`, whose `problem` is `InvalidCharacter` or
`InvalidNamespace` with the supplied spelling and context or namespace. The
location is `Unavailable(GeneratedValue)` because this name has no source text.

These are the https://dom.spec.whatwg.org/#validate[DOM construction rules].
They permit some names XML source cannot express: `a=b` is a valid computed
element local name, but `<a=b/>` is not XML. XML parsers enforce their own source
grammar; computed-name validation does not make a name serializable as XML.

== Preserve explicit identity

A `Markup.Name` can also retain an already-resolved identity directly. For
example, an HTML `createElement("H:DIV")` result has HTML namespace, `Unprefixed`,
and local `h:div`. Namespace-aware construction of `h:div` instead produces prefix
`h` and local `div`. Keep those distinct identities even though `.qualified()`
returns the same spelling.

`name.qualified()` formats the supplied prefix and local fields. It does not
infer a prefix from colons in an unprefixed local name, validate a name, or
reconstruct its namespace. Keep all three fields when lowering a name.

An unqualified attribute whose local name is `xlink:href` differs from an
XLink-namespaced attribute with prefix `xlink` and local `href`. Update and remove
attributes using namespace and local identity. Choose the downstream DOM
constructor that preserves those explicit fields and verify its result, as shown
in xref:consumer-fidelity.adoc#consumer-fidelity[the consumer-fidelity review].
