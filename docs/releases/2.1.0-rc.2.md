# roc-parser 2.1.0-rc.2

This release candidate adds the pure Roc `AsciiDoc` parser, virtual-source preprocessing and embedded HTML rendering to the Roc syntax preview in rc.1. It is built from `feat/roc-syntax-integration` for downstream testing and requires **Roc nightly `nightly-2026-10-15-38e6c42`**.

AsciiDoc development tooling includes a pinned Asciidoctor oracle, authored fixtures, independently generated models, reproducible mutations and scaling checks. Local performance checks can reuse saved Ruby baselines. This candidate includes improvements to verbatim rendering, callouts and persistent attribute storage.

Validation of the final AsciiDoc optimizations includes 1,369 package tests, 5,000 generated-input parse/render equivalence checks and the minimal CI performance smoke. Asciidoctor compatibility is incomplete; see the AsciiDoc manual for supported behavior and limits. The API may change before a final release.

The `RocSyntax` APIs from rc.1 remain included. Their requested 1.5× compiler-parser performance target is still unmet. Parsing retains explicit input and nesting limits; consumers should handle diagnostics and limited results.

Use this package dependency:

```roc
parser: "https://github.com/lukewilliamboswell/roc-parser/releases/download/2.1.0-rc.2/CZPwnt8ziVkc4v27SX7y2c8shxvPToiXiU1Y55E8tobb.tar.zst"
```

The attached examples pin this exact bundle. The release also includes the manual, API reference, compiler pin, SBOM and asset checksums. This branch preview leaves the latest stable release at 2.0.0.
