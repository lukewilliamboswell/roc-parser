# roc-parser 2.1.0-rc.1

This release candidate adds the pure Roc `RocSyntax` module for downstream syntax highlighting and syntax-based linting experiments. It is built from `feat/roc-syntax-integration` and requires **Roc nightly `nightly-2026-10-15-38e6c42`**.

`RocSyntax` provides lossless source tokens, UTF-8 byte spans, a flat indexed syntax tree, recovery diagnostics, lexer-only highlighting categories, and file/expression/statement/header entry points. The tree covers current Roc expressions, patterns, type declarations, constraints, imports and headers, including platform configuration. Legacy Rust compiler syntax is outside scope. Binding and type analysis remain future work.

The reference harness compares acceptance across all 2,191 pinned upstream inputs and compares tokens and normalized trees for every compiler-accepted input. It also includes independent generated models, oracle-backed mutations, raw-byte robustness fuzzing and editor recovery contracts.

## Status for downstream testing

- The syntax API is a release-candidate API and may change before the final release.
- Runtime optimization is ongoing. The requested 1.5× compiler-parser performance target is **not met** by this candidate. A verified buffer improvement is included; further ownership and allocation work continues separately.
- Parsing has explicit nesting and token limits. Consumers should handle diagnostics and partial/limited trees.
- This candidate does not change the latest stable release or merge the feature branch.

Use the content-addressed `.tar.zst` asset attached to this release as the package dependency. The attached examples archive includes `roc-syntax.roc` pinned to that exact bundle. The compiler pin is also attached as `.roc-version`.
