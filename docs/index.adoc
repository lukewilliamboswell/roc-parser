[.lead]
Parse text and data in Roc. roc-parser gives you small parsers that combine
into larger ones, and ready-made parsers for CSV, YAML, XML, Markdown and
HTTP/1.1 built from the same pieces.

[discrete]
== Choose a path

New to roc-parser:: Read <<overview>>, then <<getting-started>>, then
<<combinator-primer>>.
Parsing a format roc-parser already supports:: Go to its guide: <<csv>>,
<<yaml>>, <<xml>>, <<markdown>> or <<http>>.
Writing your own parser:: Read <<combinators>>, <<custom-format>> and
<<errors>>.
Looking something up:: <<modules>>, <<conformance>>, <<compatibility>> and
<<glossary>>.
Contributing to roc-parser:: Start with <<contributing>>.
