# Security Policy

## Supported versions

Security fixes are provided for the `main` branch and the latest published
release. Older releases are not supported; users should upgrade to the latest
release before reporting a version-specific issue.

## Reporting a vulnerability

Report suspected vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/lukewilliamboswell/roc-parser/security/advisories/new).
Do not open a public issue or discussion for a suspected vulnerability.

Please include, where possible:

- the impact of the vulnerability;
- the affected versions or commits;
- steps or a minimal input that reproduces the problem; and
- any known workaround or suggested mitigation.

We will acknowledge a report within 7 calendar days and provide an initial
assessment within 14 calendar days. We target coordinated disclosure within 90
calendar days. If investigation or remediation needs more time, any extension
will be agreed privately with the reporter.

Please keep the report and related discussion private until a coordinated
disclosure date has been agreed.
